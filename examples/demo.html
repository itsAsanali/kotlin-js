Kotlin.js — выполнение Kotlin прямо в браузере

Ниже подключена библиотека kotlin.js, а после неё — блок <script type="text/kotlin"> с самым обычным Kotlin-кодом. Он транспилируется в JavaScript и выполняется на лету, без сборки и без установки компилятора.

Вывод в консоль браузера / страницы

Исходный Kotlin-код (inline)

fun main() {
    val name = "мир"
    println("Привет, $name!")

    val nums = listOf(1, 2, 3, 4, 5)
    val evenSquares = nums.filter { it % 2 == 0 }.map { it * it }
    println("Квадраты чётных: " + evenSquares)

    for (i in 1..3) {
        val label = when (i) {
            1 -> "первый"
            2 -> "второй"
            else -> "остальные"
        }
        println(i.toString() + " -> " + label)
    }
}

...а так подключается внешний .kt.js файл

<script type="text/kotlin" src="app.kt.js"></script>
